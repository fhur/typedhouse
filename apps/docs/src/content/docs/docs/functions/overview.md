Functions build typed expressions inside query callbacks. Scalar methods transform or compare values; aggregate functions summarize groups of rows. They describe database work rather than executing JavaScript against fetched rows.

Each function below has its own page, with a complete TypeScript example and the **final SQL and parameters generated by the compiler**. The examples are also typechecked. The names are chql's public API names; emitted ClickHouse names can differ—for example, `element` emits `tupleElement`.
